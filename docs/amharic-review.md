# Amharic text for review

All Amharic in OpenPath, with the English it translates. It was written without a native speaker and **must be checked before real use**.

How to review: write your fix in the **Correction** column (leave it empty if the Amharic is right), or edit the files directly:

- interface text: `frontend/lang/am.json`
- onboarding questions: `frontend/public/questions/onboarding.json`
- job application questions: `frontend/public/questions/job-application.json`
- employer form questions: `frontend/public/questions/employer-accommodations.json`
- sample jobs: `frontend/public/jobs/jobs.json`

Words in `{curly brackets}` are filled in by the form (a number, a name, what the learner said). Keep them as they are.
"Simple words" is a helper the learner can turn on: short, plain versions of the same text.

_This file is generated by `frontend/scripts/amharic-review.mjs`. After changing the JSON files, run `npm run review:amharic` in `frontend/`._
